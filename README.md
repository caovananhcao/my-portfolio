# Cao Van Anh | Portfolio

A lightweight, single-file personal portfolio with a white, black/navy, and deep burgundy palette.

## Publish with GitHub Pages

1. Create a GitHub repository (for example, `portfolio`).
2. Upload `index.html` to the root of the repository.
3. Open **Settings > Pages**, select **Deploy from a branch**, then choose `main` and `/ (root)`.
4. Visit `https://YOUR-USERNAME.github.io/portfolio/` after GitHub Pages deploys.

No dependencies, build tools, or image assets are needed.
